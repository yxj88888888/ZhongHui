# sxyxerp.online 固定金价牌与分级后台设计

## 目标

将 `sxyxerp.online` 的公开页面改造成参考站 `https://www.shuibeiclub.cn/precious-metals-price-6.html` 的五行贵金属价格牌，并增加一个独立的 `/admin` 后台。公开页面使用可人工维护的固定价格，不再依赖外部实时金价源；后台按管理员、店长、店员分级控制价格和账号操作。

## 公开页面设计

公开页面继续使用根路径 `/`，不显示后台入口。视觉方向来自参考页面但使用本项目自己的 Logo、二维码和文案：

- 全屏暖棕色背景（参考页的 `#CF9F79` 色系）。
- 中央白色圆角价格卡片，Logo 居中悬浮在卡片顶部。
- 三列标题“品类 / 今日价格 / 回收价格”。
- 五行纵向价格，今日价用醒目的红色，回收价用深色强调。
- 保留现有店铺二维码；底部显示更新时间和“贵金属投资不做非实物交易”等风险提示。
- 移除当前两张大价格卡片和走势图，移动端保持单屏可读并自动缩放。

## 后台设计

后台入口固定为 `/admin`，公开页不展示链接。后台包含：

1. 登录页：账号、密码、错误提示；首次登录跳转修改密码。
2. 价格管理：五行编辑表格、正数/小数位校验、统一保存、保存后显示更新时间和修改人。
3. 用户管理：管理员创建账号、设置角色、启用/停用、删除账号、重置密码。
4. 密码管理：所有用户可修改自己的密码；管理员可重置其他账号密码。
5. 操作日志：管理员查看所有操作，店长查看价格相关日志，店员不显示日志菜单。

后台采用与公开页共享品牌色的深色金色管理风格，但保留清晰的权限和状态提示。

## 数据与接口架构

运行环境为 EdgeOne Makers 的静态页面和 EdgeOne Functions，使用 `@edgeone/pages-blob` 的强一致存储。

### Blob 键

- `gold/prices.json`：当前五行价格、更新时间、最后修改人。
- `gold/history.json`：每次价格保存的完整快照和修改人。
- `auth/users.json`：账号、角色、密码哈希、首次改密标记、状态、登录时间。
- `auth/audit.json`：登录、价格修改、改密、创建/删除/重置账号等日志。

### 公开接口

- `GET /api/gold/current`：返回五行当前价格、更新时间和单位。
- `GET /api/gold/history?range=today|week|month`：返回价格快照历史，供公开页趋势或更新时间使用。

### 管理接口

- `POST /api/admin/login`
- `POST /api/admin/logout`
- `GET /api/admin/me`
- `POST /api/admin/password`
- `GET /api/admin/prices`
- `POST /api/admin/prices`
- `GET /api/admin/users`
- `POST /api/admin/users`
- `PATCH /api/admin/users/:id`
- `DELETE /api/admin/users/:id`
- `POST /api/admin/users/:id/reset-password`
- `GET /api/admin/audit`

登录态使用 HttpOnly、Secure、SameSite Cookie，有效期 8 小时。Cookie 签名密钥从 EdgeOne 的 `AUTH_SECRET` 环境变量读取，不写入仓库。密码使用带随机盐的 PBKDF2 哈希保存；接口在服务端再次校验角色，不依赖前端隐藏按钮来保证权限。

当存储为空时，函数首次访问自动写入默认五行价格和初始管理员哈希。价格保存要求五行完整、价格为正数且最多两位小数；禁止空值、文字、负数和异常大数。

## 错误处理

- 未登录返回 `401`，权限不足返回 `403`，输入错误返回 `400`，存储故障返回 `503`。
- 公开页请求失败显示“价格暂时不可用”，不显示半截数据。
- 登录失败只返回通用提示，不暴露账号是否存在。
- 删除最后一个管理员被拒绝并记录操作尝试。
- 初始密码和 `AUTH_SECRET` 不写入源代码、测试快照或日志。

## 测试与验收

采用测试驱动开发，先为每个行为写失败测试，再实现最小代码：

- 五行价格结构、初始值和两位小数格式化。
- 价格正数/空值/非数字/超范围校验。
- 管理员、店长、店员的权限矩阵。
- 首次登录必须改密；修改后旧密码失效。
- 管理员创建、停用、删除、重置账号；禁止删除最后管理员。
- 店长可以改价但不能管理账号；店员只能查看和改自己的密码。
- 价格变更历史和审计日志。
- 公开页五行表格、后台登录页和角色菜单契约。
- EdgeOne Functions 接口响应和错误状态。

部署验收包括：公开页五行值正确、管理员首次改密成功、三个角色权限隔离、改价后公开页立即更新、日志可查、HTTPS 页面可访问。

## 不在本次范围

- 不再接入外部实时金价源。
- 不实现支付、订单结算或会员计费。
- 不复制参考站的代码、Logo、二维码或受版权保护的专属资源。
- 不把账号密码放入前端代码或 Git。
